隐私政策

Soul Agent Launcher（SAL）是一款完全离线运行的本地工具。

1. SAL 不收集、不上传任何用户个人信息、聊天记录、硬件信息或模型文件。

2. SAL 的所有数据（配置、会话、模型）均存储在用户本地设备中，开发者无法访问。

3. SAL 不会主动联网，除非用户明确触发模型下载或手动检查更新（更新服务器仅接收版本号请求，不记录任何可识别身份的信息）。

4. 本软件不开设任何云端服务，不存在用户账号体系。

5. 使用 SAL 即表示您同意本隐私政策。如您不同意，请停止使用并卸载本软件。

使用教程

快速开始

选择"一键自动部署"自动完成硬件检测、模型推荐和下载，适合新手。

自动部署后点击左侧会话菜单新建会话即可开始对话

手动启动

点击主页"启动服务"→ 弹出快速启动弹窗 → 勾选要启动的模型 → 点击"快速启动"。

API 端点

每个模型提供两个 API 端点：/chat（自研轻量协议）和 /v1/chat/completions（OpenAI 兼容），可直接接入 Soul Agent 或其他客户端。

Tips: 日常使用建议直接使用 SA Lite 在"会话"菜单进行对话即可（无 Agent 编码能力）

模型管理

在"模型"页可以下载官方推荐模型（GGUF 格式），或从本地导入已有模型文件。

配置路径

在"设置"页配置 llama.cpp 路径和模型目录。首次启动时会自动检测和安装依赖。

深度思考

支持模型的深度思考（Reasoning）能力，在对话界面可开启"深度思考"开关查看推理过程。
